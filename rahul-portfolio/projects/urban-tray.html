Urban Tray

In Development / Prototype

Overview

Urban Tray is a food-ordering and delivery application that evolved from an FOE project into an independent software-development project. It focuses on the customer ordering experience while exploring the architecture required for a broader multi-role food-delivery system.

The Problem

Coordinating food ordering between customers, restaurants, and delivery partners often means juggling phone orders, manual tracking, and disconnected tools.

The Approach

Urban Tray began within the Fundamentals of Excellence (FOE) program, then grew beyond that context into independent development. The concept is a single platform that brings ordering, menu browsing, and delivery coordination together for everyone involved — built around three roles, supported by an admin layer:

Urban Tray↕ Customer↕ Restaurant / Vendor↕ Delivery Partner

The customer-facing side is the most developed part of the concept so far; the restaurant, vendor, and delivery-partner sides are still being designed.

FOE Assignment→ Food Delivery Concept→ Branding / Logo→ Idea Expanded→ Functional Prototype→ Independent Development

My Role

I built Urban Tray's customer-facing prototype independently after it began as an FOE assignment — designing the data model and implementing the ordering flow end to end in Flask. I'm now exploring how the architecture extends to the restaurant, vendor, and delivery-partner roles.

Core Features

  • Customer registration and login
  • Menu and food browsing, with categories and food details
  • Cart and checkout with coupon support
  • Order placement, order-success flow, order history, and order tracking
  • Reviews
  • Basic admin interface for managing customer, menu, and order data

Built with Python, Flask, HTML, CSS, and JavaScript, with JSON-based data storage, tracked in Git/GitHub.

Challenges

  • Designing for multiple user roles (customer, restaurant, delivery partner)
  • Managing the order lifecycle end to end
  • Modeling relationships between customer, menu, and order data
  • Managing a growing project scope
  • Moving from concept to a working prototype iteratively

What This Project Demonstrates

  • Product thinking
  • Web and backend development
  • UX flow design
  • Data management
  • Scope management
  • Iterative development
